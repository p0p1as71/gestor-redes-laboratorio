# ACT-01 — PRUEBAS DE FUNCIONAMIENTO DE LA RED

**Estado:** ENUNCIADO CAPTURADO; entrega no acreditada.  
**Fuente:** captura del campus, 10/10/2026.

## Petición del curso

Realizar pruebas de red desde consola, indicando resultados y adjuntando capturas:
1. Ping a una dirección IP.
2. Ping a la puerta de enlace.
3. Ping a Google.
4. Ping a un nombre de equipo.
5. Repetir pruebas usando `tracert` y mostrar resultados.
6. Mostrar información de `ipconfig`.
7. Repetir con `ipconfig /all` y explicar diferencias.

El enunciado describe `ping` como método de verificación de conectividad; técnicamente una respuesta ICMP no prueba la disponibilidad de todos los servicios.

## Entrega pendiente

Documento con contexto del sistema, comandos usados, capturas y resultados *reales*. Para Windows, `tracert`/`ipconfig`; para Linux los equivalentes no son idénticos y deben explicarse por separado.
