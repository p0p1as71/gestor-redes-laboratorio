# Inventario físico

**Fuente canónica prevista:** NetBox. Este directorio contiene criterios, fichas complementarias y capturas sanitizadas, no un inventario paralelo independiente.

Campos de control: dispositivo, función, entorno, fabricante/modelo, interfaces, VLAN, IP, MAC (revisar exposición pública), puerto del switch, estado y evidencia de última verificación.
