# Prácticas

Cada práctica debe partir de un concepto del curso, tener un objetivo medible y producir una observación verificable. Una actividad planificada no equivale a una práctica ejecutada.

Usar [plantilla de práctica](plantillas/PRACTICA.md). Temas previstos: switching, routing, VLAN, DHCP/DNS, NAT/firewall y diagnóstico.
